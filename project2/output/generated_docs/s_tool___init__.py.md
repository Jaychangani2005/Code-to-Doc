# s_tool Module
================

## Overview
------------

The `s_tool` module is a Selenium wrapper designed to simplify the process of automating web browsers. It provides a convenient interface for interacting with web elements, making it easier to write efficient and effective test scripts. This module is built on top of the Selenium library and is licensed under the MIT License.

## Dependencies
------------

### Internal Dependencies

This module does not import any internal dependencies.

### External Libraries Used

*   `importlib.metadata`: This library is used to retrieve the version of the `s_tool` package.

## Usage Example
--------------

Here's an example of how to use the `s_tool` module to retrieve its version:

```python
from s_tool import __version__

print(__version__)
```

This code snippet imports the `__version__` attribute from the `s_tool` module and prints its value to the console.
